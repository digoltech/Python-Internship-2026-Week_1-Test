# **Q1. Library Management System**

### **Problem Statement**

Develop a simple **Library Management System** using Python. The system should allow users to add books, view available books, issue books, and return books.

Your solution must use **Object-Oriented Programming (OOP)** concepts and functions to organize the code properly.

The objective is to check your understanding of classes, objects, constructors, methods, lists, functions, loops, and conditional statements.

## **1. Create a&#x20;**`Book`**&#x20;class**

Create a class named `Book` with the following attributes:

- `book_id`
- `title`
- `author`
- `is_available`

Use a constructor (`__init__`) to initialize these attributes.

**Example:**

```
book = Book(101, "Python Basics", "John Smith")
```

By default, every newly added book should be available.

## **2. Create a&#x20;**`Library`**&#x20;class**

Create another class named `Library`.

It should maintain a list of book objects.

Implement the following methods:

| Method                 | Description                   |
| ---------------------- | ----------------------------- |
| `add_book(book)`       | Add a new book to the library |
| `view_books()`         | Display all books             |
| `issue_book(book_id)`  | Issue a book using its ID     |
| `return_book(book_id)` | Return an issued book         |
| `search_book(book_id)` | Find a book using its ID      |

**Important rules:**

- A book ID must be unique.
- A book can only be issued if it is available.
- An already issued book cannot be issued again.
- Only an issued book can be returned.
- If a book ID does not exist, display an appropriate message.

## **3. Create the Main Menu**

Create a menu-driven program that allows the user to perform library operations.

```
========== LIBRARY MANAGEMENT SYSTEM ==========

1. Add Book
2. View All Books
3. Search Book
4. Issue Book
5. Return Book
6. Exit

Enter your choice:
```

The menu should keep running until the user selects option `6`.
