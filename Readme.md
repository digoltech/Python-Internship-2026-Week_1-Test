## 3. Submission Guidelines

- **Section 1.1:** Write all 20 MCQ answers in `mcq_answers.py`.
- **Section 1.2:** Solve each debugging question in a separate Python file. Add a short comment explaining the correction.
- **Section 1.3:** Submit the complete working Library Management System using OOP concepts.
- Write clean, readable, and properly structured code.
- Do not copy code from other interns.
- Push all files to your GitHub repository.
